# PhysicsBank：给物理老师用的本地题库

PhysicsBank 是一个运行在自己电脑上的高中物理备课工具。您可以收集题目、按教材章节整理、导入试卷、查看公式和插图，再挑题组成新试卷。题库默认保存在本机，不会因为打开网页就自动上传。

它是在 [MathBank](https://github.com/JudgePeach/math-question-bank) 的基础上改造的物理版本，内置人教版高中物理课程目录，支持单选、多选、填空、实验、计算和简答题。

## 可以用它做什么？

- **存题、找题**：把题干、图片和解析放在一起，按章节、题型或多个考查知识点查找。
- **整理旧试卷**：导入图片、PDF 或 Word 试卷，辅助识别和拆题；公式、单位、电路图等重要内容请在保存前人工核对。
- **组卷、导出**：选题组成试卷，可导出 Word、LaTeX 源码；电脑装有 XeLaTeX 后还可编译 PDF。
- **按需使用 AI**：配置自己的模型服务后，可辅助识题、解题和选题；不用 AI 也能录题、检索和组卷。
- **查使用问答**：点击「QA」，按主题或关键词查找安装、导入、排版、导出和备份等常见问题；无需联网，也不会调用 AI。

### 按章节整理、检查待归类题目

在「题库管理」点击 **章节目录**，展开教材、章节和小节，即可按目录找题。目录数字表示全库数量；仍可搭配题型、难度或关键词缩小范围，不需要时点「清除筛选」。侧栏关闭后不占题目预览空间。

「待归类」会列出教材、章节、题型或难度未填、或已不在当前设置中的题目。打开题目补充分类并保存即可；没填小节、标签或独立知识点，不会因此被判为待归类。自定义题型也会出现在题型筛选中。

首页新增 **题库分布**，可查看题型、难度、标签、来源，以及教材小节覆盖和知识点待确认数量。一个题目有多个标签时会分别计数；读取失败会保留上次统计并提示刷新，不会把题库显示成零。这些功能只在本机统计，不调用 AI。

### 按考查知识点找综合题

在题目「编辑 → 分类」里搜索并选择知识点，可以分别标为「主要考查」和「辅助知识」。首版内置 80 个物理知识点，支持常用别名搜索；找不到时可新增个人知识点。教材位置、个人标签仍独立保留，旧题不会被自动重新分类，也不要求补齐标注才能保存。

在题库「筛选 → 知识点」中，可选择「任意一个」或「同时包含全部」，还可只看主要考查或尚未标注的题。例如同时选择「动量守恒定律」与「动能定理」，寻找相关综合题。目录可展开，草稿也保留标注。

手动标注和查找不调用 AI。需要时可点「AI 分类」：使用同一次分类请求，结合题干和已有解析推荐知识点，并显示原文依据。**AI 建议先标为“待确认”**，请核对后逐项确认、修改或移除；旧题不会被自动补标。

主线 `main` 已整合按物理需要适配的 MathBank 3.0 和 3.0.1 通用改进，保留截图录题、原图纠错和试卷图片缩放；旧便携包尚未重新发布。升级前请先做完整备份并正常关闭服务；新版首次启动会先保存数据库升级快照，再升级所需数据表。旧版程序不能直接打开升级后的数据库，回退须恢复升级前的完整备份，并另行保留升级后新增的数据。

完整的采用范围、物理版保留规则和验收记录见[本轮适配说明](docs/mathbank-3-physics-adaptation.md)。

### 给同事分享题目

打开「系统设置 → 题库分享」，按来源、题型、章节或知识点筛选，勾选题目并导出 ZIP。分享包包含所选题目、解析、分类和引用的配图，不包含程序、API 密钥或运行设置。发送前仍请检查题目许可和个人信息。

接收方在同一页面选择「导入分享包」。系统先校验并自动完整备份，再追加题目，不覆盖已有题目。**重复导入会再次添加**，不会自动合并；请保留导入前备份，避免反复导入同一包。

导入和导出现在显示处理阶段与进度。关闭设置、刷新或断线后，可查询原任务，不必重新上传。若提示“结果需要核实”，请先检查题库和备份，不要直接重导；确认再次新增同一包时需主动勾选。程序会提前检查目录能否写入，遇到权限、空间或文件占用问题会说明处理办法，不会自行提权或搬动题库。

### 导入、排版更方便

除 PDF、Word、LaTeX 外，现可导入 Markdown 文件。系统尽量保留可靠原文，只补充分类信息；未完成部分会保留诊断和已成功结果。截图支持一次框选后按网格切出多幅配图。表格、列表和图片尺寸设置也会用于预览与导出；缺失的配图会在导出前提示。

PDF/Word 的额外原文核验默认关闭，需要时手动开启，可能增加模型费用；请求失败后不会自动重试或静默换模型。Word 恢复入口需用户点击，恢复仍可能发起尚未完成的请求。上游的 PDF 本地工程、片段拆题和断点实验目前仍关闭，不属于本轮已开放功能。

### 截图里的配图，不用另存再上传

打开「导入中心 → 截图／图片录题」，可以点击上传、拖入图片，或按 Ctrl／⌘ + V 粘贴截图：

- **单题截图**：选择一张只含一道题的图片，可勾选「自动生成 AI 解答与详细解析」，再点击「识别这道题」。系统先识图，再为没有原答案的题目生成解析；不勾选则只识图。已有答案保留，明确缺图或公式待核对时请先修正；最后在编辑器核对、补充分类并保存。
- **整页／多题拆分**：适合一图多题或多张连续页面。用「上移／下移」调整图片顺序，点击「开始拆题」，再逐题审查和入库。最多 20 张，单张 10MB、总计 50MB；多题拆分需要识图模型和试卷拆解模型。

选图和调整顺序只在本机进行，点击识别／拆题后才请求模型。TeX 的「配套插图」只关联已有源码里的图片；题目截图请使用上面的图片入口。

在题干或解析的「识图」中粘贴截图，默认勾选「原图抠图」：识别文字时同时定位配图，直接从原截图裁出，放回正文、选项或表格。定位不准时点击「截图补入此处」或「重新截图」，在同一张原图上框选即可；也可从原图追加截图。

裁图本身不调用 AI，也不需要 LaTeX；首次识别仍使用您配置的识图服务。请核对裁框是否包含全部图形、标注、坐标轴和电路连接。系统不额外自动调用模型核验；取消「原图抠图」会按图调用 AI 重绘，可能额外计费。

上述功能与三阶段后端解耦现已整合到 `main` 源码。旧 Windows 便携包不会随本地源码更新；请核对所下载构建的提交，不要直接覆盖个人数据。

公式预览现支持正体常数 `\iu` / `\upi`（虚数单位）和 `\eu` / `\upe`（自然常数）；普通电流变量 `i`、电荷符号 `e` 不会被改写。兼容旧题库时，启动清理也会保留自定义知识点，不再自动清空。

PDF、Word 等试卷的**自动拆题需要配置试卷拆解模型的 API Key**；如果某页文字或公式无法可靠提取，还需要配置支持图片输入的识图模型。系统不会把识别不可靠的页面当作正确原文直接导入。

### PDF／Word 导入有什么改进？

- **尽量保留原文**：可靠的题干、公式和原答案直接保留；只有不能可靠提取的部分才进入识别与拆分流程。
- **核对更有依据**：保留相关原页、插图和公式诊断。出现「待核对」时，请对照原稿修正，不表示题目已完整识别。
- **减少图片意外丢失**：导入卡片保存时复制临时图片，避免同图被多题使用后失效；被清理的图片进入本机保留区，可按原引用恢复。保留区不自动过期，会占用磁盘空间，也不是完整备份的替代品。
- **费用由您控制**：额外原卷核验默认关闭；识图或拆题失败不会自动重复付费请求。系统保留可用结果和错误原因，是否重试由您决定。

升级源码前请先完整备份，并在自己的 Python 环境中重新安装 `requirements.txt`；本次 PDF 提取组件已升级。

## Windows 用户：如何开始？

推荐使用 **PhysicsBank Windows 便携包**，适用于 Windows 10/11 的 64 位电脑，内含 Python 和运行所需组件；普通使用无需自行安装 Python。

1. 打开 [Windows 便携包下载页](https://github.com/HalHa8/physics-question-bank/actions/workflows/ci.yml?query=branch%3Amain)，点开最近一次带绿色对勾的 **CI** 记录，在页面下方的 **Artifacts** 下载 `PhysicsBank-Windows-x64`。下载可能需要登录 GitHub。
2. 将下载的压缩包解压，找到其中的 `PhysicsBank-Windows-x64.zip`，再把这个 ZIP **完整解压到一个独立文件夹**。不要只把启动文件单独拖出来运行。旁边的 `.sha256` 文件供校验下载完整性使用。
3. 双击解压目录里的 **`启动题库系统.bat`**。浏览器通常会自动打开；否则访问 <http://127.0.0.1:8000/>。

便携包是 GitHub Actions 的构建附件，会定期过期；若页面没有附件，可按下面的源码方式运行或联系维护者重新构建。仓库上方 **Code → Download ZIP** 下载的是源码，**不是**便携包。题库数据库与个人设置保存在解压目录；更换电脑或覆盖升级前请先备份，升级步骤见包内的 `覆盖升级说明.txt`。

如果电脑上的 MathBank 已经占用 8000 端口，请先在 MathBank 网页中正常关闭它，再启动 PhysicsBank。两个项目应放在不同文件夹，不要共用数据库。熟悉命令行的用户也可以参阅下面的源码启动方式，改用 8001 端口同时运行。

<details>
<summary>源码启动（不使用便携包的用户）</summary>

需要电脑已安装 [Python 3.10 或更新版本](https://www.python.org/downloads/)；以下示例使用 Conda 隔离环境。

```powershell
git clone https://github.com/HalHa8/physics-question-bank.git
cd physics-question-bank
conda create -n physicsbank-py310 python=3.10 -y
conda activate physicsbank-py310
python -m pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8001
```

然后访问 <http://127.0.0.1:8001/>。Conda 不是必需的，只是隔离环境的一种方式。

</details>

## AI 和排版软件需要安装吗？

**基本录题、查题和网页公式预览不需要 AI 密钥，也不需要安装 LaTeX。** 想用 AI 识图、解题或选题时，在网页设置中填写您自己的服务商信息。题目或图片会发送给该服务商，请先确认材料的隐私和使用许可。

只有在电脑上直接编译 **PDF 试卷或 TikZ 示意图**时才需要 XeLaTeX（如 TeX Live 或 MiKTeX）；导出可编辑公式的 Word 文件时建议安装 Pandoc。缺少这些软件不影响日常题库使用。

## 数据、题目版权与开源说明

**不要打包整个程序文件夹发给同事或群友。** 可用「系统设置 → 题库分享」导出选题包，或在「组卷」中导出 Word/PDF，检查许可和个人信息后再发送。完整备份用于自己恢复题库，不是选题分享包。更多注意事项见网页「QA → 安全分享题目」。

题库数据库、上传图片、备份和 API 密钥留在本机；更新或换电脑前，请自行备份这些数据，勿将其上传到公开仓库。**本项目不附带可自由转载的题库**：自行导入的题目、试卷和图片仍受各自的版权或使用条件约束。
