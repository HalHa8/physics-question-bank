# MathBank 3.0 的物理适配范围

本轮以 `codex/refactor-backend-modules` 为基线，对照 MathBank 默认分支 `bf587bbd8f7fc4ca3c181e668437849bbcb5a098`，处理此前未完成的通用改进。同步完成表示各项已有采用、物理转换或明确不采用的结论，不是把数学版文件原样覆盖，也不意味着发布了新的便携包。验收与集成回执见 [上游同步记录](upstream-sync.md)。

## 教师能直接使用的变化

| 方向 | 本版行为与入口 |
| --- | --- |
| 独立知识点 | 保留首版80项物理目录、教师个人知识点和别名。一题多点、主辅关系、任一/全部/未标注筛选；教材位置与个人标签不混为一项。 |
| AI 分类 | 同一次请求可推荐知识点并提供原文依据。新建议一律待确认，不接收模型伪造的“已确认”；编辑器和导入卡片均可人工确认、移除。保留实验、计算、简答三类物理主观题；实验题中的填空不把整题改为填空题，选择题仍需教师确认单选/多选。 |
| 安全分享 | 系统设置→题库分享，选题导出带格式版本的 ZIP；预览/校验后自动完整备份并追加导入。不包含程序、密钥和运行配置，重复导入会重复追加，不会自动覆盖或合并。 |
| 来源与关系 | 保留来源标签、同源题目引用、子知识位置与导入回执；分享时映射题目关系，仅带被引用的安全图片。 |
| 导入可靠性 | Markdown 直接导入；Word/PDF 尽量保留可靠原文、公式、列表、表格及对应图片。失败保留诊断和可用结果，不能用“清洗成功”掩盖源文件缺失。 |
| 手动恢复 | Word 任务保留本地恢复资料，必须由用户点击并确认后继续；不会在启动时自动重发付费请求。 |
| 原图配图 | 保留自动原图抠图、手动补图和重裁；增加多图网格切分。单位、矢量、图例、坐标轴、电路拓扑不能被自动裁边或文字清洗破坏。 |
| 图片回收 | 暂存回收后保留验证用的哈希与恢复记录；合法旧链接或引用可恢复，损坏、越界或符号链接拒绝。已修复 Windows 框架路径分隔符导致旧链接恢复404的问题。 |
| 组卷导出 | Markdown 表格、列表、图片尺寸与版式同步到预览和 Word/PDF；导出前检查缺图，报告可定位问题。保留源码及已有错误诊断。 |
| 大题库 | 索引查询、轻量摘要与后台导出合并，提交成功后再更新衍生文件；导出期间的新写入不会被遗漏。 |

## 物理版保留和有意不采用的内容

- **不导入数学目录或平台白名单**：默认仅公开 P 物理课程；A/B/S/H 只保留已有数据兼容。数学平台 N/X、数学95k目录和第三方题库授权宣传不成为物理版默认内容。分享格式保留 MathBank 协议标识用于互通，不冒充题目版权许可。
- **不覆盖模块化后端**：`main.py` 仍为薄兼容入口；21个领域模块通过冻结的依赖契约装配，运行状态在 RuntimeState。新分享与文档项目边界单独注册，不反向导入 main，也不恢复单体全局状态。
- **不默认增加费用**：额外原文视觉核验默认关闭；开启前提示费用。模型请求不自动重试、不静默切换服务商或模型；失败后的进一步请求需教师手动发起。原始响应和已成功组不因后续失败而被抛弃。
- **PDF 实验不开放**：与上游默认一致，`PDF_CLOUD_ONLY=True`。本地文档工程、片段拆题、分片修复、并行/断点实验的底层源码保留，但默认路由关闭，不宣传为当前可用功能。其内部实验调用预算不是本版已开放工作流；以后启用前须另做物理、费用和恢复验收。
- **不搬宣传与发行号**：保留 PhysicsBank 图标、群二维码、QA、0.1.0应用标识、AGPL历史和原作者声明；不复制 MathBank 3.0 的发行号、数学样题、群资料或下载宣传。LICENSE、NOTICE不改。
- **不重写教师资料**：不根据正文自动补旧题标签、重分类或清空知识点。数学旧教材名称修复只处理已证明属于对应旧教材的镜像行，不把物理“必修第一册”改成“必修一”。

## 数据库与依赖

PhysicsBank 使用**本项目 schema v12**，不是套用 MathBank 的 v14。v11的三张知识点表继续保留，新增题目子知识关系、来源标签、题目引用和文档导入回执及必要索引。迁移先做快照、校验值域和外键，失败回滚；重复启动不重复迁移，不改旧题题干、解析、分类和图片引用。完整备份同步校验这些表。

升级前仍请完整备份并正常关闭服务。旧程序不能直接读取升级后的库；回退需要恢复升级前完整备份，并另行保留升级后新增内容。本轮只在空库和合成库验收，**未对用户现用题库执行迁移**。

依赖仅在独立验证环境中把 `pdf-inspector` 从0.2.7升级到1.25.2，并锁定在 requirements.txt；Python3.10.21及其他锁定依赖保持一致，`pip check` 验证。原 `physicsbank-py310` 可用环境未改。没有安装新的系统软件、复制真实资料或发起付费模型请求。

## 契约审阅与测试来源

本轮处理上游 `763b345`（3.0）和 `bf587bb`（测试可移植性），同时补齐此前2.5/2.6/2.7已审阅但未完成的通用依赖。三个版本的旧记录仍作为历史保留，不能把当时的“待处理”理解为本轮状态。

47个原领域算法逐个登记旧指纹、来源、原因及回归，32个新注册函数建立契约；另审阅4个原文档算法。保留原路由名称与方法，只新增22个操作。旧 OpenAPI 操作指纹不变，4个既有表单组件仅增加可选字段；新增接口使路径数由50变为71。没有整体重录契约来掩盖失败。

测试由原有项目测试、上游通用测试的适配，以及新增物理回归组成，不是全部重新生成。新增合成场景覆盖物理量单位大小写、向量正负号、有效数字、电路图片像素、个人知识点、待确认依据、题包关系往返、备份优先迁移和禁止付费重试。浏览器使用源码副本、空库、随机端口和模拟模型响应；原生导出使用既有 Pandoc/XeLaTeX。

Windows 测试只在缺少符号链接特权（WinError1314）时跳过对应原生文件操作，其他错误仍失败；纯路径安全回归继续执行。长文件名夹具缩短完整路径但仍保留溢出版面检验，滚动测试等待实际可见状态。浏览器截图核对补出了待确认入口和物理题型显示问题，均增加行为回归，不以隐藏提示或放宽内容断言代替修复。
